使用教學

內部{{ site_name }}:建立專案,以版本為單位發布程式,讓同事搜尋、瀏覽、下載。

快速上手

  1. 登入 —— 點右上角「登入」,使用公司帳號(Keycloak)登入。 已在其他平台系統登入過的話,進站會自動帶入,不必再按。
  2. 等待開通 —— 首次登入後帳號是「待開通」狀態。 依開通指引頁把你的識別碼提供給平台管理員,開通後才能建立專案。
  3. 建立專案 —— 左側欄或導航列的「建立專案」, 填入代號(網址用)、名稱與簡介;可見性選 internal(全公司可見)或 private(僅成員)。
  4. 建立版本 —— 進入專案頁按「建立版本」,填版本號(例:v1.0.0)與版本說明。
  5. 上傳三類檔案 —— 在上傳頁為這個版本上傳 更新文件(doc)、執行檔(binary)、原始碼包(source)各至少一個(見下節規則)。
  6. 發布 —— 三類齊備後「發布這個版本」才會亮起;發布後檔案即鎖定不可再變更, 要調整請開新版本。
  7. 分享與下載 —— 同事在首頁搜尋或依標籤找到專案, 從專案頁下載最新版;每個檔案都附 SHA-256 供校驗。

發布規則:每一版三類齊備

每一版發布必須包含三類檔案各至少一個,缺任何一類都無法發布 (本平台 99% 是 Python 專案,以下以 Python 產物舉例):

類型放什麼常見格式(以檔案實際內容判定)
doc 更新文件 這一版改了什麼、怎麼安裝使用 PDF、Markdown/純文字、Word(docx/doc)、PNG/JPG/GIF 截圖
binary 執行檔 可直接執行的產物(例:pyinstaller 打包) exe/ELF/Mach-O、zip/tar.gz 打包的執行檔、whl、jar、msi/deb/rpm
source 原始碼包 這一版的完整原始碼壓縮檔 zip、tar.gz、bz2、xz、7z、rar

檔案安全規則

  • 上傳以檔案實際內容(magic bytes)判型,不看副檔名; 不在白名單的型別會被拒收並說明原因。
  • HTML 與 SVG 一律拒收——它們會在瀏覽器裡被當成可執行內容, 本平台散布執行檔,不能承擔這個風險。
  • 每個檔案保存 SHA-256,下載回應也帶同一個雜湊,供你校驗檔案完整性。
  • 掃毒尚未接上前,檔案誠實標示 not_scanned;下載前請自行判斷來源信任度。
  • 單檔與專案容量有上限,超限會明確告知目前用量與上限。

回報問題與提交功能需求

發現網站問題(錯誤頁、上傳失敗、顯示異常),或想提交功能需求, 請聯絡平台管理員(與帳號開通同一位)。回報問題時請附上:

  • 重現步驟:從哪一頁、做了什麼操作、按了什麼。
  • 預期行為與實際結果:你以為會發生什麼、實際看到什麼(截圖更好)。
  • 發生時間與網址:方便管理員對照系統紀錄。

功能需求會依開發計畫排入任務;已知的範圍界線 (git clone/push、PR/code review、線上編輯等)目前不在平台規劃內。
