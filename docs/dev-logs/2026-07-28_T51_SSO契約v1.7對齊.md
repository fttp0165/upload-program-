## 計畫(動工前成文,憲法第二條 2)

### 目標

把「對照契約 v1.7 找出的四個缺口」收掉。逐項:

| 3 | 待開通文案未指引使用者去哪自助 | §4.3、§4.8 | 補上 Account Console 的指引 |
| 4 | §4.10 五項同源義務**沒有逐條測試**,只是「剛好有做」 | §4.10 | 寫成測試 |

第 4 項是本任務的重點。前三項是改值改字,第 4 項才是**讓這些義務不會被日後的
變更無意間破壞**——尤其 T44 要導入外部 JS,「不得把 token 存進 localStorage」
會從「反正沒有 JS」變成一條活的約束。

### 🔴 `/account` 是平台層短網址,**不帶我們的前綴**

這一項會撞到現有的紅線測試。T40 起有四個測試檔都在斷言
「頁面內**所有** `href`/`src`/`action` 都帶 `«PREFIX»`」——那是為了防 PLM 那類 404 事故。

但 `/account` 是 gateway 層的 302 轉址(契約 §2.1),**必須**是 `/account`,
加上我們的前綴就變成 `/upload/account`,那是一條不存在的路徑。

**做法:在測試裡建立一份具名的平台網址允許清單,而不是把斷言放寬。**

```python
PLATFORM_URLS = {"/account", "/login"}   # 契約 §2.1 的平台層短網址,刻意不帶前綴
```

並且**另外寫一條測試**去釘住「帳號設定連結必須正好是 `/account`」——
讓這個例外本身也被測試保護,不是一個悄悄開的洞。

> 寧可讓例外顯眼且有測試,也不要把原本的紅線斷言改鬆。
> 放鬆之後,真正的漏前綴 bug 就再也抓不到了。

### 設定值:`/account` 也要可設定

短網址是平台的東西,可能改。用 `ACCOUNT_CONSOLE_URL` 設定值(預設 `/account`),
不寫死在模板裡。這與「路徑前綴不自選」是同一個原則:**平台的東西由平台決定**。

### §4.10 五項的測試化

| 義務 | 測試方式 |
|---|---|
| cookie `Path=/«PREFIX»/` + HttpOnly + SameSite=Lax | 走一次登入流程,檢查 `Set-Cookie` 標頭的三個屬性 |
| 嚴格 CSP,禁 unsafe-inline | 斷言 CSP 含 `default-src 'self'`,且**不含** `unsafe-inline` / `unsafe-eval` |
| 前端 base path = 子路徑 | 沿用既有的「所有連結帶前綴」斷言(排除平台網址) |
| 使用者輸入的輸出一律消毒 | 沿用既有 XSS 測試;另加「模板中禁用 `\|safe`」的原始碼掃描 |
| **不得**把 token 存進 `localStorage` | **掃描 `app/static/` 與 `app/templates/`**:不得出現 `localStorage` / `sessionStorage` |

最後一項是**原始碼層級的守門**,不是行為測試——因為現在沒有 JS,行為測不出來,
但 T44 加了 JS 之後這條就會真的擋人。這正是它的用途。

### `/account` 撞紅線:用具名例外,不放寬斷言

如計畫預期,加上 `/account` 之後四個測試檔的「所有連結都帶前綴」全數轉紅。

處理方式**不是**把斷言改鬆,而是在每個檔案加一份具名清單:

```python
# 契約 §2.1 的平台層短網址:由 gateway 302 轉址,**刻意不帶各 App 的前綴**。
# 這是「所有連結帶前綴」那條紅線的具名例外——例外本身在 test_sso_contract.py 有測試保護。
PLATFORM_URLS = {"/account", "/login"}
```

並另寫一條 `test_帳號設定連結不帶前綴` 去釘住這個例外。

> 放鬆斷言的話,真正的「漏前綴」bug 就再也抓不到了——
> 而那正是 PLM 出過 404 事故的原因。**例外要顯眼、要有名字、要有自己的測試。**

### 一處 regex 抓到自己的註解——這次改測試而不是改註解

`test_同源義務_模板不得使用safe過濾器` 一開始用 `\|\s*safe\b`,
結果抓到模板註解裡寫的「禁用 `|safe`」。

與 T40 那次(CSS 註解裡的 `prefers-color-scheme`)不同,**這次我改的是測試**:
`|safe` 只有出現在**輸出運算式** `{{ x|safe }}` 或 `{% filter safe %}` 裡才會關掉逸出,
註解提到它是無害的。改成:

```python
re.compile(r"\{\{[^}]*\|\s*safe\b|\{%\s*filter\s+safe\b")
```

兩次的差別在於**能不能精確表達語意**:CSS 那次做不到(字串出現在哪都可能是真的媒體查詢),
所以改註解;這次做得到,所以改測試。**判準是「哪一邊更接近要測的東西」,不是「哪邊比較好改」。**
