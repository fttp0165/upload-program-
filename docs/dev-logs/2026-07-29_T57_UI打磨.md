# T57 UI 打磨:在 T56 設計語言上做第二輪美化

**建立日期:** 2026-07-29 13:00
**最後更新:** 2026-07-29 13:35
**版本:** v1.1
**對應任務:** T57(新開)——T56 設計稿落地後的視覺打磨(Benny 口頭需求「再美化一下介面」)

---

## 計畫(動工前成文,憲法第二條 2)

### 目標

不改設計語言(藏青 + 綠、膠囊、白卡 + 漸層條、amber 警示——那是設計師定的,
不是我們可以重定義的),在**同一套語言之內**把質感補齊:

1. **動效**:互動元素(按鈕、卡片、連結、輸入框)加上一致的過渡與 hover 回饋
   ——現況只有 `.project` 有 hover 陰影,其他元素是「跳變」。
2. **層次**:陰影改雙層(貼地 + 環境光),卡片 hover 微上浮;頁面底加極淡的
   頂部漸層 wash,讓 sticky 導航列下方不是一片死平。
3. **表單**:focus 從瀏覽器預設 outline 升級為「藏青框 + 柔光圈」;
   file 拖放區 hover 給綠色暗示(呼應設計稿的拖放視覺)。
4. **細節**:版本歷史 `<details>` 加摺疊箭頭(現況看不出可展開)、
   錯誤頁大字狀態碼改漸層字、`::selection` 用強調綠、pager hover 填色。

**刻意不做**:改色盤、改字級階層、動任何模板/HTML——這輪只打磨,不重設計。
設計師驗收若有結構性意見,另開任務。

### 影響範圍

| 類型 | 檔案 |
|---|---|
| 修改 | `app/static/app.css`(唯一異動檔;純 CSS) |
| 修改 | `docs/任務表.md`(登記 T57) |

**對現有資料的影響:🟢 純前端樣式,零資料、零模板、零路由。**

### 驗收標準

1. 全部既有測試綠(337 條,不改任何斷言)——純 CSS 依 T56 經驗幾乎不撞,
   但「幾乎」不算數,要實跑。
2. `app.css` 仍無深色媒體查詢字串、無任何外部 URL(有測試字串把關)。
3. 動效全部包在 `prefers-reduced-motion: no-preference` 之內——使用者關動畫
   就真的沒有動畫(無障礙;這與被禁的深色媒體查詢是兩回事,禁的只有配色自動切換)。
4. headless Chromium 逐畫面截圖,與 T56 版比對:設計語言不變、質感提升。

### 回滾方式

`git revert`(單一 commit、純 CSS,獨立可回滾)。

## 結果(完工後補記,2026-07-29 13:35)

### 異動檔案

`app/static/app.css`(唯一)、`docs/任務表.md`(登記 T57)。

### 實際做了什麼(對應計畫四項)

1. **動效**:檔尾新增 `prefers-reduced-motion: no-preference` 區塊,互動元素統一
   `.15s` 過渡;按鈕 hover 微浮 / active 落回、專案卡 hover 上浮 2px。
   `.project` 原本寫死在外面的 `transition` 一併收進去——關動畫就真的全關。
2. **層次**:`--shadow` / `--shadow-hover` 改雙層(貼地 + 環境光);頁面頂部加
   淡漸層 wash(終點色 = 頁底色,無色階斷差);導航列改半透明白 + `backdrop-filter`
   毛玻璃(不支援的瀏覽器退回近乎不透明白)。
3. **表單**:文字輸入類 focus 統一「藏青框 + 綠柔光圈」,取代全域 outline
   (雙重框粗糙;光圈本身就是清楚焦點,無障礙不打折);file 選檔區 hover 轉綠
   (呼應設計稿拖放視覺)。
4. **細節**:`<details>` 摺疊箭頭(收合狀態原本完全看不出可展開——可供性缺口);
   404 大字改漸層字(`background-clip: text`,`width: fit-content` 讓置中的字吃到
   完整藏青→綠;`color` 留作不支援時退路);pager hover 填色;admin-tabs 補 hover
   (原本被同權重後行規則蓋掉,看起來像死字);`::selection` 用綠;progress 軌道加內陰影。

### 測試結果

**337 passed**(改後完整跑兩次:動效落地後一次、404 漸層字修正後一次);
`prefers-color-scheme` 與外部 URL 字串檢查均為 0。純 CSS,無新測試(第三條 4)。

### 驗證方式

headless Chromium 逐畫面截圖(已登入首頁、版本歷史、錯誤頁),與 T56 版比對:
設計語言不變。過程中抓到一個自己的缺陷:漸層字首版整片偏綠——漸層以**元素**為
座標,滿版元素置中的字只吃得到中段色;`width: fit-content` + `margin: auto` 修正。

### 對現有資料的實際影響

🟢 無。純樣式,未動模板/路由/資料。
