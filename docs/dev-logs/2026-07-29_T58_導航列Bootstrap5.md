## 計畫(動工前成文,憲法第二條 2)

### 目標

1. 導航列**解擁擠**:登入後的導航列現有七個項目擠一排
   (品牌、搜尋、建立專案、管理、使用者名、帳號設定、登出)。
   改用 Bootstrap 5 navbar:
   - 「使用者名 / 帳號設定 / 登出」收進**使用者下拉選單**(7 項 → 4 群)
   - 窄螢幕收成**漢堡選單**(collapse)——現況窄螢幕是 flex-wrap 疊行,更擠
2. Bootstrap 5 依 Benny 裁示引入,**自託管 vendor**(平台 CSP 禁外部資源,CDN 不可能):
   `bootstrap.min.css` + `bootstrap.bundle.min.js`(5.3.8,npm 官包原檔,含 LICENSE)。

### 技術約束盤點(動工前查證,不是猜)

| 約束 | 查證結果 | 對策 |
|---|---|---|
| CSP `default-src 'self'` 擋 `data:` URI | Bootstrap 漢堡圖示與表單圖示是 `data:` SVG,**會被擋** | **不放寬 CSP**(§4.10 有測試釘著):漢堡鈕直接用文字字元「☰」,不用 `.navbar-toggler-icon`;表單不掛 bootstrap 的 form 類,原樣式續用 |
| 深色紅線 | `bootstrap.min.css` 內 `prefers-color-scheme` **0 筆**(色彩模式是 attr 切換,我們不用) | 無需處理;字串測試只掃 `app.css`,雙保險 |
| 儲存 API 掃描(掃全 static) | `bootstrap.bundle.min.js` 內 localStorage/sessionStorage **0 筆** | 直接過 |
| 紅線「連結一律 `url()`」 | dropdown 觸發不能用 `href="#"` | 觸發改 `<button>`,零 href |
| CSP 禁 inline script | Bootstrap JS 是外部檔;collapse 動畫由 JS 設 `el.style`(CSSOM),CSP 不擋 | 掛 `static/vendor/` 外部檔 |
| 類名衝突(`.btn`/`.badge`/`.card`/`.nav-link` Bootstrap 都有定義) | Bootstrap **先載、app.css 後載**,同名屬性我方覆蓋 | 逐屬性核對;`.card` 需補 `border: none`(Bootstrap 會加 1px 框) |

### 解擁擠的實際結構

登入後導航列 7 項 → 4 群:品牌 / 搜尋 / 建立專案・管理 / **使用者下拉**

### 紅線對策(計畫表全數執行,另補三項落地時發現的)

計畫表六項全數照做。落地時另外發現並處理:

1. **Bootstrap 對 `.btn` / `.nav-link` 的 `:focus-visible` 是「`outline: 0` + 藍光圈」**,
   選擇器權重壓過我們的全域綠框——補權重相當的覆蓋,把焦點樣式搶回綠色系。
   (框架配色滲入的路徑不只主樣式,焦點態也是。)
2. **reboot 的標題是 `calc(...+vw)` 流式字級**、`code` 是粉紅——都不是本站語言,
   在 `app.css` 釘回(`h1: 2rem`、`h2: 1.45rem`、`code: inherit`)。
   標題字級從此以本檔為準,不再依賴瀏覽器預設。
3. Bootstrap 給 `.card` 加 1px 框、給 `.btn` 加透明框(撐大 2px)——補 `border: none`。
