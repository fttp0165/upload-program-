## 計畫(動工前成文,憲法第二條 2)

### 目標

T58 引入的 Bootstrap 只當導航列的結構機制;本輪把它的**版面元件**推進內容區,
做兩件看得見的優化(仍是「結構機制夠用才引用」,不為框架而框架):

1. **麵包屑**(Bootstrap breadcrumb):專案頁、版本歷史、上傳頁補導覽脈絡
   ——T56 遺留 #2 就此結案;連結一律 `url()`(紅線)
2. **專案頁響應式兩欄**(Bootstrap grid):`col-lg-8` 最新版本 / `col-lg-4` 專案資訊,
   大螢幕不必捲過整段下載區才看到容量;窄螢幕自動疊回單欄
   ——🔴 DOM 順序仍是「最新版本在前、專案資訊在後」,Q8「下載優先」的測試不動

### 影響範圍
