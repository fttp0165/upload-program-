## 計畫(動工前成文,憲法第二條 2)

### 目標(對齊 PLM 的導覽形態)

1. **左側欄**(登入且已開通才有):專案總覽 / 建立專案 /(管理員)使用者、稽核紀錄;
   圖示 + 文字、**現用項目藏青底反白**(PLM 的 active 樣式);側欄底部留版本區
2. **頂列**保留:品牌、搜尋、使用者下拉;原本頂列的「建立專案/管理」改為
   `d-lg-none`——桌面走側欄、窄螢幕仍收在漢堡裡(**不重覆顯示**)
3. 圖示用**行內 SVG**(CSP 擋 data: URI 與外部資源;行內 SVG 是標記不是資源載入)
4. `render()` 注入 `current_path`(request.url.path,剝前綴後的路徑)供 active 判斷

### 影響範圍

`app/templating.py`(+1 行 context)、`app/templates/base.html`(layout + 側欄)、
`app/static/app.css`(側欄樣式)、任務表、離線預覽。
**對現有資料的影響:🟢 純前端。**

### 驗收標準

1. 344 條測試綠(訪客首頁「無建立專案連結」等釘住行為不變——側欄僅限已開通者)
2. 桌面:側欄 + active 反白;窄幅:側欄消失、漢堡含全部連結
