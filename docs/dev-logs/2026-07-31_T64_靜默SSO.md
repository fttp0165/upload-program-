## 計畫(動工前成文,憲法第二條 2)

### 目標

匿名訪客進首頁時,以 OIDC 標準 **`prompt=none` 靜默授權**先問一次 IdP:
有 SSO session → 無聲登入直接進站;沒有 → IdP 回 `login_required`,
無聲退回落地頁。**兩種人都零多餘點擊**;落地頁(裁決核准的偏離)保留。

### 設計約束

1. **只對「瀏覽器 + 首次」發起**:條件 = `Accept` 含 text/html(沿用 T47
   內容協商精神)且無探測 cookie——curl/冒煙(`Accept: */*`)行為完全不變,
   既有測試不必改。
2. **防迴圈**:發起探測時即種短效探測 cookie(5 分鐘,HttpOnly,綁 cookie_path);
   期間不再探測。靜默失敗不是錯誤,不寫 warning log。
3. 流程仍是 Auth Code + PKCE(只是多 `prompt=none`),契約 §4.1 不變;
   callback 對非靜默流程的錯誤處理維持 401。

### 影響範圍

`app/session.py`(LoginState 加 `silent` 欄位,預設 False 向後相容)、
`app/oidc.py`(authorization_url 加 prompt 參數)、`app/routers/auth.py`
(login 支援 silent、callback 靜默失敗改無聲返回)、`app/routers/web.py`
(首頁發起探測)、tests(新檔 + fake 增補)。
**對現有資料的影響:🟢 純程式。**

### 驗收標準

紅→綠:瀏覽器首訪 302 探測/帶 cookie 200/curl 200 不變/silent 授權 URL 含
prompt=none 並種 cookie/靜默失敗無聲返回且無 session/非靜默錯誤仍 401;
全套既有測試零放寬全綠。

### 回滾方式

git revert(單一 commit)。
