## 計畫(動工前成文,憲法第二條 2)

### 目標

新增 `/help` 使用教學頁,**匿名可看**(教學頁擋登入毫無道理,待開通者也需要它):

1. **快速上手**:登入 → 開通 → 建專案 → 建版本 → 上傳三類檔案 → 發布 → 下載,一步一段。
2. **發布規則**:T65 三類齊備(doc/binary/source 各至少一)、格式白名單表
   (依 `app/filetypes.py` 現況;Python 產物對應寫明:執行檔=pyinstaller 產物 zip/exe、
   原始碼=zip/tar.gz、文件=pdf/md)、HTML/SVG 一律拒收、SHA-256 校驗、
   掃毒 `not_scanned` 誠實標示。
3. **帳號開通**:指路 `/pending`(sub 複製給管理員),不重複維護文案。
4. **回報問題 / 提交功能需求**:MVP 最小方案=頁內專節,說明找平台管理員
   (與帳號開通同一管道)、回報時要附什麼(重現步驟、預期行為、網址、時間);
   不建站內表單(那是新的資料表與權限面,需另立任務)。

入口:頂列導航(所有人可見)+ 左側欄(已開通者)各一條「使用教學」連結。

### 影響範圍

`app/templates/help.html`(新)、`app/routers/web.py`(新路由 `/help`)、
`app/templates/base.html`(導航 + 側欄連結)、`tests/test_help_page.py`(新)、
功能需求大綱(新 F 項)、任務表。
**對現有資料的影響:🟢 純新增唯讀頁面,不動資料。**

### 驗收標準

紅→綠:匿名(帶探測 cookie)GET `/help` → 200 且含教學章節與三類規則;
登入者亦可看;頂列與側欄有入口且連結帶前綴(`url()`);
頁內含回報問題/功能需求專節;全站既有測試全綠。

### 回滾方式

git revert(單一 commit;純新增頁面,無資料異動)。

## 結果(完工後補記)

### 做了什麼(異動檔案)

- `app/routers/web.py`:新增 `GET /help`(匿名可看,純靜態、不查 DB)。
- `app/templates/help.html`(新):四節——快速上手七步、三類齊備規則
  (含格式表,依 `filetypes.py` 白名單改寫成使用者語言)、檔案安全規則、
  回報問題/功能需求專節(找平台管理員 + 回報要附什麼)。
- `app/templates/base.html`:頂列加「使用教學」(所有人可見;已開通者桌面版
  `d-lg-none` 藏起避免與側欄重覆,同 T62 的處理)、側欄加同名連結
  (行內 SVG 問號圖示——CSP 擋 data: URI 與外部資源)。
- `tests/test_help_page.py`(新):6 條。
- 文件:功能需求大綱新增 F77(v3.9,§7 重算 55/50/5/0)、任務表 T66(v1.45)。

### 為什麼這樣做

- **匿名可看**:教學頁擋登入毫無道理——還沒登入、待開通的同事最需要它;
  頁面純靜態不查資料庫,不漏任何專案內容。
- **回報管道採最小方案**(頁內專節 + 找管理員):站內回報表單是新的資料表、
  權限面與通知面,超出「加一個說明頁」的裁示範圍;若之後要做,另立任務
  (可掛在 F18 站內申請單一起評估)。
- **規則文案與程式同源註記**:help.html 開頭註明規則本體在
  `releases.missing_required_kinds()` 與 `filetypes.py`,規則變了要同步這一頁。
- 捨棄的替代方案:md 文件掛在 docs/(使用者根本不會去 repo 看)、
  嵌 OpenAPI /docs(那是給 API 呼叫端的,不是教學)。
