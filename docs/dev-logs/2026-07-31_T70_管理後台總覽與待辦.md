## 計畫(動工前成文,憲法第二條 2)

### 目標

新增 `/admin` 管理後台總覽頁(管理員限定),內容為設計文件 §4.1、§4.4、§4.5:

1. **KPI 六卡**:帳號(含待開通)、專案(internal/private)、版本(published/draft)、
   檔案(含 not_scanned)、儲存(佔用 / 配額總和)、下載累計次數。
2. **需要管理員動作的待辦**(本頁真正的價值):
   待開通帳號、**逼近配額 ≥80%** 的專案、**停滯 >14 天**的 draft、
   未掃描檔案數、**擁有者已停用**的專案(提示走 F16 轉移)。
   門檻依 Benny 確認採預設值,常數集中在 `app/dashboard.py`。
3. **系統資訊**:`APP_VERSION`、環境、稽核保留天數與「清理需 cron」的既有提醒。

聚合查詢集中在新模組 `app/dashboard.py`(純函式,吃 session + settings),
T71 的趨勢與排行會擴充同一個模組——路由不寫 SQL,測試可直接對函式斷言。

導覽:`admin-tabs` 抽成共用 partial `_admin_tabs.html`(現在兩個模板各寫一份,
加第三頁就會漂移);側欄「管理」段最上方加「總覽」。
🔴 **不放 `/admin/projects` 的連結**——那一頁是 T72,現在放上去就是懸空連結。

### 影響範圍

`app/dashboard.py`(新)、`app/routers/web.py`(新增 `/admin` 路由)、
`app/templates/admin_dashboard.html`(新)、`app/templates/_admin_tabs.html`(新)、

### 驗收標準

紅→綠:
1. 匿名 → 302 去登入;非管理員 → 403;管理員 → 200。
2. **數字正確**:fixture 造出已知資料後,斷言頁面顯示的數字等於實際值
   (不是「頁面有出現數字」)。
3. 待辦清單:逼近配額、停滯 draft、擁有者停用三項各以 fixture 觸發一次,
   且**未觸發時不出現**(避免嚇人)。
4. 個資紅線:頁面不得出現 `@`(email 樣式)、不得有任何「誰下載了什麼」欄位。
5. 空狀態:零資料的平台不炸,顯示合理文字。
6. 連結一律帶前綴;無 inline style/script。
7. 全站既有測試維持全綠。

## 結果(完工後補記)

### 做了什麼(異動檔案)

- `app/dashboard.py`(新):所有聚合查詢的單一出處(`collect_kpis`、`collect_todos`、
  `human_bytes`),含門檻常數 `STALE_DRAFT_DAYS=14`、`QUOTA_WARN_RATIO=0.8`、`TOP_N=5`。
  **路由不寫 SQL**,測試可直接對函式與頁面數字斷言。
- `app/routers/web.py`:新增 `GET /admin`(沿用 `_require_web_admin`,不另立權限規則)。
- `app/templates/admin_dashboard.html`(新):KPI 六卡 + 待辦 + 系統資訊。
- `app/templates/_admin_tabs.html`(新):分頁列抽成共用 partial,
  `admin_users.html` / `admin_audit.html` 改用它(原本各寫一份)。
- `app/templates/base.html`:側欄「管理」段最上方加「總覽」(行內 SVG 長條圖圖示)。
- `app/static/app.css`:KPI 卡與待辦清單樣式(沿用既有 token,不新增設計語言)。
- `tests/test_admin_dashboard.py`(新):13 條。

### 為什麼這樣做

- **數字正確才是這一頁的價值**,所以模板每個數值都帶 `data-metric`,測試用它精確定位,
  斷言「等於實際值」而不是「頁面有出現數字」——後者讓錯的數字照樣過關。
- **待辦清單只在觸發時出現**:沒事的時候顯示「目前沒有需要處理的項目」,
  不擺一排空表格嚇人;三項判準各有一條「未觸發時不出現」的測試。
- **配額總和按級距加總**,不用「專案數 × 標準級距」草率帶過——有擴充級距(F17)
  的專案會讓那個算法失真。
- **停滯 draft 的時間界線在 Python 端算好再帶進 WHERE**:SQLite(測試)與
  PostgreSQL(正式)的間隔語法不同,寫進 SQL 會綁死其中一種。
- **`_aware()` 補時區**:SQLite 不保存時區、PostgreSQL 保存,相減混用會 TypeError
  並讓整頁 500;這種環境差異在讀取端一次收掉。
- **分頁列抽 partial**:第三頁一加,兩份手寫的分頁列必然漂移(與站名、版本號同一個病)。
- 🔴 **不放 `/admin/projects` 連結**(T72 才有),並用測試釘住——懸空連結比沒有連結更糟。
