## 計畫(動工前寫,第二條 2)

### 目標

使用教學頁(`/help`)加上**內嵌 SVG 圖示**,把「七個步驟」與「頁面長什麼樣、按鈕在哪」
畫出來,而不是只有一串文字清單。

Benny 要求(附截圖):「教學加上 頁面圖 的 svg 檔 視覺化教學」。

現況的問題:七個步驟全是文字,而使用者卡住的地方通常是**空間問題**
(「建立版本的按鈕在哪一頁」、「三個上傳格子是同一頁還是三頁」),
文字回答不了空間問題。

### 做法

三張圖,依使用者實際會卡住的順序:

1. **流程圖**——七步從登入到下載,標出「三類齊備才亮起發布」這個唯一的閘門。
2. **頁面圖**——側欄 + 三個主要畫面(首頁 / 專案頁 / 上傳頁)的示意,
   標出每一步該按的位置。這是 Benny 要的「頁面圖」本體。
3. **三類齊備圖**——doc / binary / source 三格與發布鈕的狀態關係。

🔴 **一律內嵌 SVG,不放 `<img src>` 也不用 data: URI:**
CSP 是 `default-src 'self'`,data: URI 直接被擋(base.html 的圖示註解已記過同一件事);
而內嵌是標記、不是資源載入,離線可開、無外部依賴,也符合第四條 5。

🔴 **圖不得與文字步驟漂移**:圖裡的七步標籤與 `help-steps` 清單以測試對釘,
改一邊沒改另一邊會紅——圖與文字互相矛盾比沒有圖更糟。

⚠ 圖檔放在獨立的模板 `_help_diagrams.html` 並 include,不直接塞進 help.html:
三張 SVG 的座標與路徑會把教學文字擠到看不見,而以後改文案的人只想改文字。

### 影響範圍

- `app/templates/_help_diagrams.html`(新增)
- `app/templates/help.html`(include + 圖說)
- `app/static/app.css`(圖的容器樣式:置中、`max-width: 100%`、窄螢幕可橫向捲動)
- `tests/test_help_diagrams.py`(新增)

**對現有資料的影響:🟢 不動**(純靜態頁面,不查資料庫、無 migration)。

### 驗收標準

1. `/help` 匿名可見,含三張 `role="img"` 且有 `<title>` 的內嵌 SVG。
2. 🔴 SVG 內**不得**出現 `<script>`、`<image>`、`http(s)://`、`data:`
   ——離線可開與 CSP 兩件事都靠這一條。
3. 圖裡的七步標籤與教學清單的七步一致(測試對釘)。
4. 全套測試綠燈。

### 回滾方式

`git revert` 單一 commit;純模板與樣式。

### 為什麼是內嵌而不是 `.svg` 檔加 `<img>`

- CSP 是 `default-src 'self'`:`data:` URI 直接被擋(base.html 的圖示註解已記過同一件事)。
- 內嵌是**標記**、不是資源載入:離線可開、無外部依賴、無額外請求,符合第四條 5。
- 顏色只能寫死十六進位:presentation attribute 不吃 `var()`,而 `style="…"` 是
  inline style,同樣被 CSP 擋。**設計 token 改色時這裡要一起改**,已寫在檔頭。

### 對現有資料的實際影響

### 遺留問題與後續建議

1. 顏色與 `app.css` 的 token 是**兩份**(CSP 造成),token 改色時圖不會自動跟上。
   目前靠檔頭註解提醒;要更硬的話得寫一條「圖裡出現的色碼必須都在 token 表內」的測試。
2. 窄螢幕靠 `min-width: 34rem` + 橫向捲動(縮到看不見比捲動糟);手機上是捲的。
3. 圖與文字的一致性目前只釘住**七步標籤**;頁面圖裡的側欄項目若日後增減,測試抓不到。
