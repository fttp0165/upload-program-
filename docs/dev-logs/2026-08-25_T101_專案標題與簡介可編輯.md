## 計畫(動工前寫,第二條 2)

### 目標

Benny:「專案標題與內容 發布者都可以編輯」。

專案頁加一個編輯表單,讓 **maintainer 以上**改 `name`(標題)與 `summary`(內容/簡介)。

### 🔴 施工前讀 API 時發現的權限不一致(本任務一併修)

`PATCH /v1/projects/{slug}` 要求 **maintainer**,而它的 `ProjectUpdate` **包含
`visibility`** —— 也就是說 **maintainer 現在可以改「誰看得到」**。

而 T100(昨天)剛把可見性定為 **owner 專屬**(介面與 web 路由都是)。
兩者相加的結果是:**maintainer 繞過介面打一次 API,就能把 private 專案改成全公司可見。**

⚠ **這不是排版不一致,是內容外洩的路徑。** T100 的計畫書自己寫過
「介面若比 API 寬鬆等於開了第二套規則」—— 這次是**反過來**:API 比介面寬鬆,
而寬的那邊才是真正生效的那邊。

**修法:`PATCH` 收到 `visibility` 時要求 owner**(name / summary 維持 maintainer)。
🔴 這是**收窄**權限,不是放寬:對既有呼叫端的唯一影響是
「maintainer 用 API 改可見性」從成功變成 403 —— 而那正是該被擋掉的事。

### 做法

1. 專案頁「編輯專案」表單(maintainer 以上可見):標題 + 簡介 → `POST /projects/{slug}/edit`
2. 規則與 API 共用:web 路由用 `require_project_role(..., maintainer)`,
   實際寫入沿用 `ProjectUpdate` 的長度限制(name 1–128、summary ≤2000)
3. 新增稽核 `project.update` —— 改名會改變「大家怎麼稱呼這個專案」,值得留痕
4. `PATCH` 的可見性改為 owner-only,並補正反兩條測試

### 影響範圍

- `app/routers/projects.py`(PATCH 的可見性授權)
- `app/routers/web.py`(新路由)
- `app/templates/project.html`(編輯表單)
- `app/audit.py`(`project.update`)
- `tests/test_project_edit.py`(新增)

**對現有資料的影響:🟢 不動。** 無 migration;既有專案的 name/summary 不變。

### 驗收標準

1. maintainer 可在專案頁改標題與簡介;viewer 看不到那個表單也打不動端點。
2. 🔴 **maintainer 用 `PATCH` 改 `visibility` → 403**;owner → 200。
3. 改標題/簡介留稽核。
4. slug **不可改**(它在網址裡,而平台沒有轉址;T96 已載明這個代價)。
5. 全套測試綠。

### 回滾方式

`git revert`;無資料異動。⚠ 回滾會**一併退回**那條權限收窄 —— 那不是我們想要的,
所以真要回退介面時請只 revert 介面部分。

### 🔴 本任務真正的價值是那條權限收窄

`PATCH /v1/projects/{slug}` 只要 maintainer,而 `ProjectUpdate` 含 `visibility`。
T100 昨天把「誰看得到」定為 owner 專屬 —— **但只在介面與 web 路由上**。
於是 maintainer 打一次 API 就能把 private 專案改成全公司可見。

T100 的計畫書寫過「介面若比 API 寬鬆等於開了第二套規則」;
這次是**反過來:API 比介面寬鬆**,而**寬的那邊才是真正生效的那邊**。
兩條測試(maintainer → 403、owner → 200)+ 一條「只收窄 visibility 不連坐 name」。

### 刻意不做的兩件事

1. **短名不可改** —— slug 在網址裡而平台沒有轉址,改它會讓別人貼出去的連結直接死掉
   (T96 已載明這個代價)。畫面上明寫這句話,而不是讓人試了才發現。
2. **可見性不放進這個表單** —— 那是 owner 的職權(T100 的區塊)。
   同一張表單裡混兩種權限,遲早有人把它們一起放寬。

### 對現有資料的實際影響

🟢 **不動。** 無 migration;既有專案的 name/summary 不變。

   實際是**舊的 devserver 程序還在跑舊程式碼**。重開就好。
