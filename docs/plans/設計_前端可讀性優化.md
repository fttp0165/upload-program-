## 1. 需求

Benny:「依據 UI/UX 美化優化前端頁面」。

## 2. 先講不做什麼:不重設計

T56 已有一套設計語言(藏青主色 + 強調綠、膠囊按鈕、白卡片 + 漸層條、amber 徽章),
而**版面沒有測試守著** —— 大改版面是「改了才知道哪裡壞」的變更。

🔴 **所以本任務的原則:不換皮,修「看得懂」。**
從 2026-09-08 專案頁的實際截圖裡挑出的是**資訊呈現**的問題,不是配色問題:

| # | 截圖裡看到的 | 問題 |
|---|---|---|
| 1 | `195245216 / 2147483648 bytes(standard 級距)` | 人看不出是 186 MB / 2 GB。**管理總覽早就有 `human_bytes`,只有那一頁在用** |
| 2 | `191254 bytes` · `195047936 bytes` | 同上,每個檔案都是裸位元組 |
| 3 | `source` · `binary` · `doc` | 上傳頁三格卡片寫「說明 / 程式碼 / 執行檔」,**檔案清單卻顯示英文 enum** —— 同一個東西兩種名字 |
| 4 | `未掃描 not_scanned` | 中英雙寫,徽章一半是給程式看的 |
| 5 | `/upload/v1/projects/…/download` 折成兩行的純文字 | 「固定連結」存在的意義是**貼進文件**,但它是純文字、只有路徑沒有 host —— 貼出去不能點 |
| 6 | SHA-256 一整行 64 碼 | 校驗要用**完整值**,不能截;但目前要用滑鼠精準拖選 64 個字 |
| 7 | `識別碼(顯示名稱待平台核准)` | **過時文案** —— 契約 v3.4 已核准(T132),那句話現在是錯的 |

## 3. 做什麼(七項,全部零 JS、無 migration)

1. **`human_bytes` 註冊為 Jinja filter**,單一真相 = 既有的 `dashboard.human_bytes`。
   全站裸位元組改為 `186.2 MB`,**原始 bytes 放在 `title`** —— 要精確校驗大小的人 hover 就有。
   範圍:`project.html`(3)、`releases.html`、`upload.html`(3)、`admin_users.html`(4)、
   `admin_reviews.html`、`issue_detail.html`。
2. **檔案類別顯示中文**:`source → 程式碼`、`binary → 執行檔`、`doc → 說明`。
   🔴 單一真相 = `releases.py` 的 `REQUIRED_KINDS`(上傳頁卡片用的那份),不另寫一份對照表。
3. **掃毒徽章只留中文**,英文 enum 值移到 `title`。
4. **固定連結變成可點的絕對網址**(`public_base_url` + 路徑),
   加 `user-select: all` —— 點一下就全選,右鍵複製就是能貼進文件的東西。
5. **SHA-256 保留完整值**,但加 `user-select: all` + `word-break: break-all`:
   點一下全選,不必拖 64 個字。**不截短** —— 校驗用的東西截了就沒用。
6. **移除「顯示名稱待平台核准」**:有名字顯示名字,沒名字顯示 `sub` 前 8 碼 + 「尚未登入過,沒有名字」。
7. **容量進度條加顏色門檻**:≥ 80%(與管理總覽 `QUOTA_WARN_RATIO` 同一個數字)轉 amber。

## 4. 影響範圲

- 模板 6 支、`app.css`、`templating.py`(註冊 filter)
- **對現有資料的影響:🟢 不動。** 純顯示層。
- **不動任何路由、不動任何 API 回應**(bytes 在 API 裡維持整數 —— 那是給程式看的)。

## 5. 驗收標準(先寫會失敗的測試)

1. 🔴 專案頁**不再出現** `\d{7,} bytes` 這種裸位元組(反向斷言,用正則掃整頁)
2. 🔴 檔案清單顯示「程式碼」而不是 `source`
3. 🔴 固定連結是 `<a href="https://…">`,且 href 以 `public_base_url` 開頭
4. 🔴 「待平台核准」四個字不再出現
5. `human_bytes` filter 的單元測試(1023 B / 1.0 KB / 186.2 MB / 2.0 GB)
6. 既有 70x 條全綠(版面守門:Q8「下載優先」DOM 順序等測試不得動)

## 6. 回滾方式

還原模板與 CSS。🟢 無資料變更。

## 7. 刻意不做

- **不換配色、不換字體、不動側欄** —— T56 的設計語言維持
- **不引入 JS**(複製按鈕之類)—— `user-select: all` 已達到目的,而 CSP 下每一段 JS 都是成本
- **不做深色模式** —— 憲法第四條明文禁止
