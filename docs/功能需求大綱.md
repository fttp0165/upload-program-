## 0. 一句話定義

**公司內部的開發者程式分享平台**:登入後建立專案,在專案內上傳**原始碼、執行檔、程式文件**,
以**版本**為單位發布,同事可以瀏覽、搜尋、下載。

做的是「**有版本管理的程式發布倉庫**」,不是分散式版本控制系統。

---

## 1. 使用者角色

| 角色 | 定義 | 能做什麼 |
|---|---|---|
| **訪客** | 未登入 | 只能被導向登入頁,看不到任何內容 |
| **待開通使用者** | 首登建立,零角色(`pending`) | 只能看到自己的身分與「請找管理員開通」的指引 |
| **一般使用者** | 已開通(`active`) | 建立自己的專案;瀏覽/搜尋/下載所有 internal 專案 |
| **專案 viewer** | 被加入專案的成員 | 讀取與下載該專案(含 private) |
| **專案 maintainer** | 被加入專案的成員 | viewer 權限 + 建版本、上傳檔案、發布 |
| **專案 owner** | 專案建立者 | maintainer 權限 + 改專案設定、管成員、刪除專案 |
| **平台管理員** | `platform_role=admin` | 開通/停用帳號、指派平台角色;可見全部專案 |

> **權限原則:deny-by-default。** 身分由 Keycloak 認證,但「能做什麼」完全由本平台自己決定,
> 不碰 Keycloak 的角色設定。

---

## 2. 主要使用情境

| # | 情境 | 流程 |
|---|---|---|
| U1 | **第一次使用** | 開站 → 導向 SSO 登入 → 回站後看到「待開通」指引 → 管理員開通 → 可用 |
| U2 | **發布一個工具** | 建立專案 → 建立版本 v1.0.0 → 上傳執行檔 + 原始碼 + 使用說明 → 發布 |
| U3 | **找別人的工具來用** | 搜尋關鍵字 → 開專案 → 看版本列表 → 下載執行檔 → 用 SHA-256 校驗 |
| U4 | **發新版** | 開既有專案 → 建立版本 v1.1.0 → 上傳新檔 → 發布(舊版仍在,可回頭下載) |
| U5 | **內部限定的工具** | 建專案時設 private → 加入指定同事為成員 → 只有成員找得到、下得到 |

## 3. 功能需求

**優先級:** P0 = MVP 必要 / P1 = MVP 應有 / P2 = 之後再說
**狀態:** ✅ 已實作(未驗證)/ ⬜ 未實作 / 🔒 已實作但阻塞於外部條件

> ⚠️ 「已實作」僅表示程式碼存在。專案至今**測試未執行**(欠項 A1),
> 任何 ✅ 都不等於已驗證可用。

### A. 帳號與權限

| 編號 | 功能 | 說明 | 優先 | 里程碑 | 狀態 |
|---|---|---|---|---|---|
| F01 | SSO 登入 | 走 Keycloak(Auth Code + PKCE);**不自建帳號、不存密碼** | P0 | M3 | 🔒 待 client 申請 |
| F02 | 首登自動建帳號 | 自動建立零角色本地帳號;業務庫**只存 `sub`** | P0 | M3 | ✅ |
| F03 | 待開通指引 | 未開通存取業務功能一律 403,文案指引「找 upload-program 管理員開通」 | P0 | M3 | ✅ |
| F04 | 查看自己的身分 | 顯示開通狀態與角色;email/姓名由 IdP 即時提供,不落地 | P0 | M3 | ✅ |
| F05 | 單一登出 | 導向 IdP 登出端點,登出後所有接入 App 都需重登 | P0 | M3 | 🔒 待 client 申請 |
| F06 | 延續登入 | access token 過期時以 refresh token 續期,不必重打帳密 | P1 | M3 | ✅ |

### B. 專案管理

| 編號 | 功能 | 說明 | 優先 | 里程碑 | 狀態 |
|---|---|---|---|---|---|
| F10 | 建立專案 | 短名(網址用)、名稱、簡介、可見性;短名全站唯一 | P0 | M4 | ✅ |
| F11 | 專案列表 | 只列出當事人看得到的專案,支援關鍵字與分頁 | P0 | M4 | ✅ |
| F12 | 專案詳情 | 基本資料 + 自己在該專案的角色 | P0 | M4 | ✅ |
| F13 | 編輯專案 | 改名稱、簡介、可見性(maintainer 以上) | P0 | M4 | ✅ |
| F14 | 刪除專案 | owner 限定;**連同所有版本與檔案一併清除**,不留孤兒物件 | P1 | M4 | ✅ |
| F15 | 成員與角色 | 加入/調整/移除成員,三種角色(owner/maintainer/viewer) | P0 | M4 | ✅ |
| F16 | 轉移擁有權 | 把 owner 移交他人 | P2 | — | ⬜ 未實作 |

**可見性規則**

- `internal`(預設):所有已開通使用者可讀、可下載
- `private`:僅成員可讀;**對非成員一律回 404**,不洩漏該專案是否存在

### C. 版本發布

| 編號 | 功能 | 說明 | 優先 | 里程碑 | 狀態 |
|---|---|---|---|---|---|
| F20 | 建立版本 | 版本號(專案內唯一)+ 發布說明;初始為 **draft** | P0 | M4 | ✅ |
| F21 | 編輯發布說明 | draft 階段可反覆修改 | P0 | M4 | ✅ |

| F23 | 發布後鎖定 | 已發布的版本**不可增刪檔案**,避免同一版內容被偷換;要改就發新版 | P0 | M4 | ✅ |
| F24 | 版本列表 | 非成員只看得到已發布版本;draft 是作者的工作區 | P0 | M4 | ✅ |

### D. 檔案上傳與下載

| 編號 | 功能 | 說明 | 優先 | 里程碑 | 狀態 |
|---|---|---|---|---|---|
| F30 | 三類檔案上傳 | `source`(原始碼)/ `binary`(執行檔)/ `doc`(程式文件) | P0 | M5 | ✅ |
| F31 | 大檔上傳 | 數百 MB 等級;串流處理,記憶體不隨檔案大小成長 | P0 | M5 | ✅ |
| F32 | **判型與拒收** | 驗 magic bytes,不信副檔名與前端宣稱的型別;各類別有白名單;**HTML/SVG 一律拒收** | P0 | M5 | ✅ |
| F33 | SHA-256 校驗值 | 每個檔案保存雜湊供使用者自行校驗;可與上傳端宣告值比對,不符即作廢 | P0 | M5 | ✅ |
| F34 | 容量限制 | 單檔上限與專案總容量上限,超過回 413 | P0 | M5 | ✅ |
| F35 | **安全下載** | 一律 `Content-Disposition: attachment` + `nosniff`;絕不讓上傳內容在本網域被瀏覽器執行 | P0 | M5 | ✅ |
| F36 | 刪除檔案 | 僅 draft 版本可刪 | P1 | M5 | ✅ |
| F37 | 掃毒狀態 | 下載處誠實標示掃描狀態;**未接掃毒前一律標 `not_scanned`** | P0 | M5 | ✅(標示)|
| F38 | 病毒掃描 | 實際接上掃毒引擎(ClamAV) | P2 | — | ⬜ 未實作(待決策 T25)|

> **為什麼 F32/F35 是 P0 而不是「加分項」:** 這是一個**散布可執行檔**的平台。
> 若讓上傳內容以 HTML/JS 在本服務網域被瀏覽器執行,等於自己開一個 XSS 給全公司。

## 4. 非功能需求

| 面向 | 需求 |
|---|---|
| **安全** | 不自建帳號/不存密碼/不自簽 JWT;業務庫只存 `sub`;上傳驗 magic bytes;下載強制 attachment |
| **效能** | 大檔上傳記憶體固定;DB 連線池 ≤20 |
| **可用性** | `/health` 啟動 60 秒內回 200;SIGTERM 後 30 秒內優雅關閉,換版不斷既有請求 |
| **相容性** | 服務掛在 gateway 子路徑 `/«PREFIX»/` 下且前綴會被剝掉,所有對外連結都要正確 |
| **可維運** | log 可依 `trace_id` 跨服務追查;migration 可雙向回滾 |
| **合規** | 通過 Cats 接入指南 §11 的 Definition of Done 全部檢查項 |

## 5. 範圍外(MVP 不做)

與開發計畫書 §1.2 一致:

| 不做 | 理由 |
|---|---|
| git 協定(`clone`/`push`)、commit 圖、diff | GitHub 的核心難點;本平台以「版本化的檔案集」取代 |
| Pull Request / code review | 第二期再議 |
| Issue 追蹤 | 第二期再議 |
| 線上編輯程式碼 | 上傳既有產物即可 |
| CI 建置 | 本平台不負責編譯 |
| 外網公開 | 內部平台,登入才可見 |
| 留言 / 評分 / 訂閱通知 | 非核心,先確認平台有人用再說 |
