建立日期: 2026-08-12 00:10 最後更新: 2026-08-12 01:20 版本: v1.1 對應任務: T90 適用對象: 測試工程師(與所有做驗收的人)

這份回答「測什麼」——依這個系統的實際功能逐項列出;流程規矩(怎麼測)見 測試SOP。

怎麼用: - 換版冒煙:只跑「冒煙」欄打 ✓ 的項目,15–20 分鐘。 - 全回歸:大版本(次版號跳動)或動到登入/權限時跑全表。 - 新功能驗收:跑該區全部 + 〈安全跨切面〉。 - 結果逐項記 ✅ / ❌ / 未驗(含原因)——「沒驗到」不得記成「驗過了」。

分工: 方式欄 ✅ = 自動測試已覆蓋(CI 每次跑,人工抽查即可); 🖐 = 人工項,是測試工程師的主力——真實 Keycloak、貼上/拖放/取消這類瀏覽器 行為、跨 App 登出、視覺版面、VM 上的 cron 與備份,自動化構不到。

A. 登入與 SSO(13)

# 測試項目(條件 → 動作 → 預期) 方式 冒煙
A-01 未登入,從 portal 卡片點進 /upload/ → 直接到 Keycloak 登入畫面,不停任何中間頁 ✅+🖐(302 由 smoke.sh 驗;IdP 畫面人工) ✓
A-02 先登入 portal(IdP 已有 session)再進 /upload/ → 免按登入直接進專案總覽 🖐 ✓
A-03 帳密正確登入 → 302 回站內;登入狀態顯示名字與登出鈕 🖐 ✓
A-04 未登入直開深層頁(/projects/xxx)→ 302 登入 → 登入後回到原頁 ✅+🖐
A-05 竄改 next 為外部網址 → 登入後不得轉出站外(只收站內相對路徑) ✅
A-06 登入後停留 6 分鐘再操作(access token 300 秒已過期)→ 無感續期,不被登出 ✅+🖐
A-07 IdP 端已終止(停權/登出)後再操作 → 視為未登入 → 送登入頁,不是錯誤頁 ✅
A-08 待開通者開首頁 → 302 回平台入口;直開 /pending → 看到自己的 sub 可複製 ✅+🖐
A-09 停用者嘗試登入 → 不建立 session、302 回入口,不會無限彈跳 ✅
A-10 按登出 → 導向 IdP 登出 → 回站內;開另一個 App 驗證也已登出(單一登出) 🖐 ✓
A-11 在別的 App 按登出 → 本服務 session 一併清除(front-channel;待 portal 登錄後驗) ✅+🖐
A-12 curl(非瀏覽器)打首頁 → 200 落地頁(監控判準,不隨登入改動而變) ✅
A-13 DevTools → Application:localStorage / sessionStorage 無任何 token ✅+🖐

B. 帳號與開通(7)

# 測試項目 方式 冒煙
B-01 全新帳號首次登入 → 建為待開通;開通前所有功能頁都進不去 ✅+🖐
B-02 /admin/users 待開通清單:名字(IdP 有給時)+ 申請時間 + 完整 sub ✅
B-03 按「開通」→ 對方立即可用;稽核出現一筆 user.activate(含操作者名字) ✅+🖐
B-04 停用使用者 → 對方下一個請求即被擋,不必等 cookie 過期 ✅
B-05 管理員嘗試停用自己 → 被拒且有明確訊息 ✅
B-06 bootstrap 名單內的 sub 首登 → 自動 active + admin(解第一個管理員的死結) ✅
B-07 IdP 改名後重新登入 → 後台顯示新名;IdP 拿掉名字 → 顯示退回 sub(不留舊名) ✅

C. 專案(10)

# 測試項目 方式 冒煙
C-01 建立專案(合法 slug + 名稱)→ 出現在總覽與搜尋 ✅+🖐 ✓
C-02 slug 重複 → 明確錯誤;slug 不合法(大寫/空白/中文)→ 拒收 ✅
C-03 private 專案:非成員列表看不到、直開 404(不洩漏存在) ✅
C-04 internal 專案:所有已開通者可讀;只有 maintainer 以上可建版本/上傳 ✅
C-05 加成員(viewer / maintainer)、移除成員 → 權限即時生效 ✅
C-06 轉移擁有權 → 新 owner 可管理;稽核留 project.transfer_owner ✅
C-07 關鍵字搜尋、標籤篩選(含中文標籤)、超過 20 筆分頁 ✅+🖐
C-08 設定/修改標籤 → 專案卡片與篩選連結同步更新 ✅
C-09 上傳至專案用量 ≥80% → 管理總覽出現配額警示 ✅
C-10 超過專案容量上限(2 GB/擴充 10 GB)→ 上傳被拒,訊息說明原因 ✅

D. 版本發布(8)

# 測試項目 方式 冒煙
D-01 建 draft 版本;同專案同版本號重複 → 409 ✅
D-02 draft 對非成員不可見(歷史列表與直開皆是) ✅
D-03 三類不齊 → 發布鈕鎖住 + 列出缺哪類;直接打 API 發布也被 422 擋下 ✅
D-04 doc + source + binary 齊備 → 發布成功;發布後上傳卡片消失、檔案不可再變更 ✅+🖐 ✓
D-05 重複按發布(重整後再送)→ 冪等,不報錯不重複 ✅
D-06 latest 指向最新發布的版本(先建後發不影響;v9 / v10 不被字串排序騙) ✅
D-07 歷史頁依發布時間倒序 ✅
D-08 版本說明含特殊字元(<b> 等)→ 顯示為純文字,不被執行 ✅

E. 上傳(10)

# 測試項目 方式 冒煙
E-01 上傳頁為三格卡片(說明→程式碼→執行檔),各格自帶選檔與上傳鈕,無類型下拉 ✅
E-02 三類各傳一件正確檔(PDF→說明、zip→程式碼、執行檔→執行檔)→ 各格 ✓ 檔名、頂線轉綠 🖐 ✓
E-03 型別錯配(zip 丟「說明」格)→ 被退回,訊息說出原因(magic bytes,不信副檔名) ✅+🖐
E-04 HTML / SVG 一律拒收——含改副檔名偽裝(.html 改 .pdf 照樣拒) ✅
E-05 超過單檔 100 MB → 前端先擋;繞過前端直打 API 也被擋 ✅+🖐
E-06 中文/空白/# 檔名 → 上傳、顯示、下載皆正常 ✅
E-07 上傳中按「取消」→ 立即中止、介面復原、顯示「已取消」(不是卡在 47%) 🖐
E-08 上傳中斷網 → 顯示連線中斷,可直接重試 🖐
E-09 連線假死(不回應)→ 10 分鐘逾時自動放行,介面不永久鎖死 🖐(抽測)
E-10 檔案 SHA-256 與本機 sha256sum 一致;掃毒欄誠實顯示 not_scanned ✅+🖐

F. 下載(6)

# 測試項目 方式 冒煙
F-01 下載任一檔 → 瀏覽器下載而非開啟(attachment + nosniff) ✅+🖐 ✓

G. 問題回報(13)

# 測試項目 方式 冒煙
G-01 送出回報(標題 + 內文)→ 出現在自己的清單,狀態 open ✅+🖐 ✓
G-02 Markdown:粗體/清單/程式碼/https 連結正常;<script>、javascript: 連結 → 無害純文字 ✅
G-03 內文貼外部圖片連結 → 圖被剝除不顯示(不外連) ✅
G-04 詳情頁 Ctrl+V 貼上截圖 → 自動上傳並插入;拖放檔案亦可 🖐
G-05 附件上限:單檔 >5 MB 拒、第 6 個拒、非 png/jpeg/gif 拒 ✅
G-06 附件圖在頁面上 inline 顯示;他人直打附件網址 → 404 ✅
G-07 別人的回報:非管理員清單看不到、直開 404(不洩漏存在) ✅
G-08 管理員看得到全部、可留言、可改狀態;非管理員改狀態被拒 ✅+🖐
G-09 狀態流轉:open→in_progress→resolved;回報人對 resolved 仍可留言說「還是不行」;closed / wontfix 結案 ✅+🖐
G-10 待開通者也能送出回報(網站壞掉時最需要回報的正是登不進來的人) ✅
G-11 管理總覽待辦「未處理的回報 n」= open + in_progress 的正確數 ✅
G-12 關閉 JS 再測:基本回報(表單送出)仍可用——貼圖只是增強 🖐
G-13 purge_issues.py:不加 --yes 只預演不刪;--yes 只刪 closed/wontfix 滿 365 天 ✅+🖐

I. 安全跨切面(9)

# 測試項目 方式 冒煙
I-01 DevTools Console:全站瀏覽一輪無 CSP 違規來自本服務頁面 ✅+🖐
I-02 回應標頭:nosniff 全站;X-Frame-Options 只有一個(gateway 送的) ✅
I-03 API 錯誤是 RFC 7807;瀏覽器錯誤頁含 trace_id;500 不洩 stack ✅+🖐
I-04 拿錯誤頁的 trace_id 到伺服器 log 找 → 找得到同一筆 🖐
I-05 抽查 log:無密碼、無完整 JWT、無個資;OIDC 失敗只記 error 碼 ✅+🖐
I-06 session cookie:HttpOnly + SameSite=Lax + Secure(DevTools 檢查) ✅+🖐
I-07 跨站表單 POST(另開網頁對本站發)→ 不生效(SameSite 防線) ✅
I-08 權限矩陣抽測:viewer 不能上傳/發布;maintainer 不能動專案設定(owner 限定項) ✅
I-09 repo 與 CI:無 secret/.env 入 git;紅線掃描(零 Authentik、零 HS256)綠 ✅
