**建立日期:** 2026-08-12 00:10

**對應任務:** T111
**適用對象:** 測試工程師(與所有做驗收的人)

> 這份回答「**測什麼**」——依這個系統的實際功能逐項列出;流程規矩(怎麼測)見
> [測試SOP](測試SOP.md)。
>
> **怎麼用:**
> - **換版冒煙**:只跑「冒煙」欄打 ✓ 的項目,15–20 分鐘。
> - **全回歸**:大版本(次版號跳動)或動到登入/權限時跑全表。
> - **新功能驗收**:跑該區全部 + 〈安全跨切面〉。
> - 結果逐項記 ✅ / ❌ / **未驗**(含原因)——「沒驗到」不得記成「驗過了」。
>
> **分工:** 方式欄 ✅ = 自動測試已覆蓋(CI 每次跑,人工抽查即可);
> **🖐 = 人工項,是測試工程師的主力**——真實 Keycloak、貼上/拖放/取消這類瀏覽器
> 行為、跨 App 登出、視覺版面、VM 上的 cron 與備份,自動化構不到。

```
旅程:登入SSO(13) → 帳號開通(7) → 專案(10) → 版本(8) → 上傳(10) → 下載(6) → 回報(13)
跨切面:管理後台(8)・安全(9)・部署維運(7)・介面(6)      合計 97 項
```
