1. 系統定位與部署現況

  • 系統: upload-program——公司內部開發者程式分享平台(「AI 小程式分享平台」,T69 更名), 簡易型 GitHub:登入後建立專案,上傳原始碼、執行檔、程式文件,以版本為單位發布、瀏覽、搜尋、下載。
  • 技術: Python 3.12 + FastAPI + PostgreSQL + MinIO(物件儲存)。
  • 部署: Cats 共用 VM,經 portal-gateway 掛載於子路徑 catsapp.sporton.com.tw/upload/,✅ 已上線(cats-portal 系統清單)。
  • MVP 不做: git 協定(clone/push)、PR / code review、issue、線上編輯、CI 建置、外網公開。 一句話界線:有版本管理的程式發布倉庫,不是分散式版本控制系統。
